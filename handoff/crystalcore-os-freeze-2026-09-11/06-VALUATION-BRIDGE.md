# Valuation bridge — company vs product

The 2026-09-11 audit priced the **software/IP artifact**, not TerAustralis Incognita.

| Object | Point | Range | What is in the number |
|---|---|---|---|
| CrystalCore.OS artifact (today, ND license, no independent test log, public tree 404) | **USD 95,000** | 35,000–220,000 | Code + specs + tests as surveyed |
| Same artifact after this freeze is *executed* (tag + license split + second-machine tests + live demo) | **USD 140,000–180,000** expected midpoint | 80,000–280,000 | Still not a kernel; now deliverable |
| Replacement cost (do not ask this) | — | 180,000–450,000 | Rebuild time |
| TerAustralis Incognita the company | **not priced** | — | Needs books, ABN, contracts, pipeline, brand. Zero revenue was assumed. |

## Why the freeze moves the number at all

Buyers pay for take-home-ability. Today the discount stack is:

1. Name says OS, tree says web shell + backend
2. License is NC-ND
3. Source not fetchable on a public URL
4. Tests are author-reported
5. Demos advertised and dead

This pack attacks 1–5. It does not create users, revenue, or a security audit. Those are the next jumps (security review → upper half of range; one paying design partner → company valuation conversation, which is a different spreadsheet).

## What not to say in the room

- “The OS is worth $450k because another harness was.” Different artifact, different freeze quality.
- “Replacement cost is $2.5M.” That number was the other project’s ceiling, not ours.
- “Lattice integrity 100%.” Vision. Kills diligence.
- “Company value equals product value.” The company currently *is* the founder plus the artifact. That is a lifestyle/IP vehicle until there is a book.
