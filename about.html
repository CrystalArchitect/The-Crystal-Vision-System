What this site is — and is not

The formal proposal package for a Southern Hemisphere terrestrial node and CrystalCore, a local-first intelligence layer. It exists to be read, criticised, and — if the argument holds — acted on. Documents 01–12 argue for what should exist. Document 13 — What Is Built records what already does, dated and checkable.

Not a funding solicitation

The Ask is technical review, criticism, and partnership discussion. No investment is sought at this stage.

Not a claim of partnership

No organisation named in these documents has endorsed, reviewed, or agreed to anything. Where a company, agency or site appears, it appears as public context or as a thing being asked for — never as a thing already secured.

Not a running system

The Lattice and the wider TerAustralis vision are locked by the project's own Constitution as designed, not built, and every status document says so.

How to respond

The proposal is public and so is the workshop behind it. The reliable channel is GitHub: open an issue on github.com/CrystalArchitect/teraustralis-proposal, or on whichever repository your question is about. Technical criticism is welcome in the same place as everything else, which is the point.

How to verify what this package claims

Every load-bearing claim here is meant to be checked, not taken:

  • The reference implementation is public. The engine, the companion, the consent gate and their test suites live at github.com/CrystalArchitect with CI running on every push — 137/137 automated checks at repository head, re-verified on a fresh machine 10 August 2026.
  • The creative canon is timestamped. A deterministic SHA-256 manifest over the work is anchored to Bitcoin via OpenTimestamps by CI, with each proof committed back into the repository. No wallet, no token, nothing traded — timestamping only, verifiable by anyone with the repository and an ots client.
  • The ledger is public and admits what is missing. The portfolio's status file opens with its own rule — "This file describes the state of the system, not the ambition of the system" — and carries a corrections file that records errors in place rather than quietly editing them.
  • The live site — the main TerAustralis Incognita site, distinct from this proposal package's own domain — is www.teraustralis.com.au.

How AI is used here, stated plainly

This project is built with AI assistance and does not pretend otherwise:

  • Every pull request names the AI tools that helped produce it. That is a governance requirement, not a courtesy.
  • AI-generated documents are filed as received documents with authority weight zero — never as evidence, never as members, never as consent. Several such records are published verbatim in the archive alongside findings on what they got wrong, including breaches of the project's own naming law.
  • A model cannot consent, and is never counted as if it had.
  • The honesty law is enforced in code, not only in prose. The message bus rejects any claim that does not declare its evidence layer — science, vision, or governance — and the project's founding rule is that no dreamed line may pretend it was measured.

Indigenous knowledge — a stated boundary

The project's standing position is that this is "not AI that contains Songlines, but AI infrastructure capable of respecting the laws that already govern them." No Indigenous cultural knowledge enters any model, dataset or index without Free, Prior and Informed Consent from the relevant custodians, and intent to obtain consent later is not consent. Work is held back — including material prepared for this package — when the consent door belongs to custodians rather than to the project.
