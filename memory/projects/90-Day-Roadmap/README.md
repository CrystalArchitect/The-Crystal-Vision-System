## What this is

A public-accountability commitment: 8 subjects, one shippable deliverable
each, each with an externally-verifiable success metric ("PDF with ASA
lodgement ID, verifiable by outsider," "public Gist/repo... one external
person can read/run it"). Every metric is checkable by someone outside
the project — that's the point, and it's the same discipline this repo's
own Incognita Rule asks of Built-layer claims generally: verifiable, not
self-asserted.
