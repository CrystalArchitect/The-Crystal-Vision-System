# 07 — Bayesian Thinking (The Predictors)

**Purpose:** Update beliefs with evidence. Prior → Evidence → Posterior.

**CrystalCore mapping:** Register ARCHIVE | Primitive track() + Bayesian update | Persistent state must store priors

## Core Questions — Run these, do not summarize

1. What was our prior belief and confidence?
2. What new evidence arrived and how diagnostic is it?
3. What is the likelihood of this evidence if prior is true vs false?
4. What is the posterior belief after update?
5. What evidence would change our mind back?

## Required Concrete Output — No vague labels

- Prior (belief + %)
- Evidence + Diagnosticity
- Likelihood Ratio
- Posterior
- Crux / Falsifier

## Evidence → Interpretation → Experiment → Record

- **Evidence:** What was measured / observed?
- **Interpretation:** What gap / affect / loop does this reveal?
- **Experiment:** Smallest test to verify?
- **Record:** CHRONICLE entry as ARCHIVE / LOOM / FORGE / MIRROR

## Anti-Pattern

Do not just name "Bayesian Thinking". Produce the artefact listed above. If no artefact, you have not run the model.
