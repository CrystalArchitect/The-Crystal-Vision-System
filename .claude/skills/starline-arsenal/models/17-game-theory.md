# 17 — Game Theory (The Predictors)

**Purpose:** Model the other players, their incentives, and the moves that are stable once everyone reacts.

**CrystalCore mapping:** Register MIRROR | Primitive label_affect() across incentives | Anticipate rival moves before committing a closure policy

## Core Questions — Run these, do not summarize

1. Who are the players and what does each actually want?
2. What is each player's best move given what the others are likely to do?
3. Is there a stable outcome (equilibrium) once nobody wants to switch unilaterally?
4. Is this a one-shot game or repeated — does reputation change the payoff?
5. Where could changing the rules (not the play) produce a better equilibrium?

## Required Concrete Output — No vague labels

- Player / Incentive Table
- Payoff Matrix (or sketch)
- Equilibrium Call
- Rule-Change Option

- **Evidence:** What was measured / observed?

- **Experiment:** Smallest test to verify?
