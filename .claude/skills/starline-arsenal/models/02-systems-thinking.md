# 02 — Systems Thinking (The Deconstructors)

**Purpose:** Map stocks, flows, feedback loops, delays, leverage.

**CrystalCore mapping:** Register LOOM | Primitive track() | Gap persists where loop is unseen

## Core Questions — Run these, do not summarize

1. What are the stocks (accumulations) and flows (rates)?
2. Where are reinforcing (R) and balancing (B) loops?
3. Where is the delay that hides the consequence?
4. Where is the bottleneck / constraint?
5. Where is the highest leverage point with lowest effort?

## Required Concrete Output — No vague labels

- System Map (stocks/flows/loops)
- Delay Map
- Bottleneck
- Leverage Audit (1-5 points)

- **Evidence:** What was measured / observed?
- **Interpretation:** What gap / affect / loop does this reveal?
- **Experiment:** Smallest test to verify?
