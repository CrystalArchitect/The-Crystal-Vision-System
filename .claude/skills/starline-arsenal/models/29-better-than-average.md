# 29 — Better-Than-Average Thinking (The Predictors)

**Purpose:** Check a self-assessment of "above average" against an actual named crowd and count, not a feeling.

**CrystalCore mapping:** Register MIRROR | Primitive label_affect() on self-vs-crowd placement | Most people place themselves above a midpoint they have never actually measured

## Core Questions — Run these, do not summarize

1. Who, specifically, is the crowd being compared against?
2. Has anyone actually measured where the midpoint of that crowd sits?
3. Is "above average" a feeling, or a count?
4. What would the base rate look like if everyone made this same claim?
5. Is there a named exception-case, or just "I am the exception" with no count behind it?

## Required Concrete Output — No vague labels

- Crowd Named
- Midpoint Known or Unknown
- Claim vs Count
- Correction (if the claim outruns the count)

## Evidence → Interpretation → Experiment → Record

- **Evidence:** What was measured / observed?
- **Interpretation:** What gap / affect / loop does this reveal?
- **Experiment:** Smallest test to verify?
- **Record:** CHRONICLE entry as ARCHIVE / LOOM / FORGE / MIRROR

## Anti-Pattern

Do not just name "Better-Than-Average Thinking". "I am the exception" with no count behind it means you have not run the model.
