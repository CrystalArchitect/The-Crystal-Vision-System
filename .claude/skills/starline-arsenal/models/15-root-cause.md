# 15 — Root Cause Analysis (5 Whys) (The Deconstructors)

**Purpose:** Chase a symptom back through cause and cause until it stops moving.

**CrystalCore mapping:** Register LOOM | Primitive track() causal chain to origin | A gap treated at the symptom layer just re-opens

## Core Questions — Run these, do not summarize

1. What is the observed symptom, exactly?
2. Why did that happen? (1st why)
3. Keep asking why of each answer — where does the chain stop giving new information?
4. Is the stopping point a root cause or just a convenient place to quit?
5. What fix at the root prevents the whole chain, not just the symptom?

## Required Concrete Output — No vague labels

- Why-Chain (symptom to root, minimum 3 links)
- Root Cause Statement
- Symptom-Fix vs Root-Fix Comparison
- Prevention Action

## Evidence → Interpretation → Experiment → Record

- **Evidence:** What was measured / observed?
- **Interpretation:** What gap / affect / loop does this reveal?
- **Experiment:** Smallest test to verify?
- **Record:** CHRONICLE entry as ARCHIVE / LOOM / FORGE / MIRROR

## Anti-Pattern

Do not just name "Root Cause Analysis". Produce the artefact listed above. If no artefact, you have not run the model.
