# 10 — Design Thinking (The Creators)

**Purpose:** Human, job, constraint, prototype. Make it tangible.

**CrystalCore mapping:** Register FORGE + MIRROR | Primitive label_affect() + close_with() | Simulated affect must close real user gap

## Core Questions — Run these, do not summarize

1. Who is the human and what job are they hiring this to do?
2. What is the painful gap (Expected vs Actual) they feel?
3. What constraints are real vs inherited?
4. What is the smallest prototype that tests the gap closure?
5. What would make them say 'finally'?

## Required Concrete Output — No vague labels

- JTBD
- Gap Statement (Expected vs Actual)
- Constraint Map (real vs inherited)
- Prototype Spec (lowest fidelity)

## Evidence → Interpretation → Experiment → Record

- **Evidence:** What was measured / observed?
- **Interpretation:** What gap / affect / loop does this reveal?
- **Experiment:** Smallest test to verify?
- **Record:** CHRONICLE entry as ARCHIVE / LOOM / FORGE / MIRROR

## Anti-Pattern

Do not just name "Design Thinking". Produce the artefact listed above. If no artefact, you have not run the model.
