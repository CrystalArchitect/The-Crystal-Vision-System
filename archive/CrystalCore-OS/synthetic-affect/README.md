# Synthetic Affect Theory™ — retired here, 2026-08-14

**This directory no longer holds the runnable package.** The split was
granted (G2, 2026-08-14): the theory's canonical home is now
[`CrystalArchitect/Synthetic-Affect-Theory`](https://github.com/CrystalArchitect/Synthetic-Affect-Theory-)
— the trailing hyphen in that link is the repository's actual current name;
renaming it to drop the hyphen is a manual step in that repository's own
settings, not yet done as of this entry.

> **Synthetic = apparent / functional, for design purposes. Not a claim of
> feeling, consciousness, or inner experience.** That line, and everything
> it implies, lives at the new home now — not repeated here.

## What used to be here

`core/`, `tests/`, `experiments/` (the prediction-1 harness),
`examples/`, `crystalcode/SPEC.md`, `docs/` (`FIGURE-1.md`,
`GLOSSARY.md`, `figure-1.svg`, `lyrics/`), and `THEORY.md` — the full
package, byte-for-byte reconciled with the new home as of the grant. All
of it is still in this repository's git history if you need it; none of
it is deleted from the record, only from this directory going forward.

## What's still here

- **[`CHRONICLE.md`](CHRONICLE.md)** — the full dated record, unedited:
  the original defects found and fixed here, the prediction-1 harness and
  its adversarial review, the two-repo reconciliation, and the grant
  itself. This is the only place that history lives in full; the new
  home's own `CHRONICLE.md` starts from its own landing, not from here.
- **[`ATTRIBUTION.md`](ATTRIBUTION.md)** — unchanged, the contributor
  record for what was built in this directory specifically.

## Why retire rather than leave both live

Running two live copies already caused a real defect: a PR into the
dedicated repository shipped a classifier-ordering bug this package had
already found and fixed, because nothing pointed from one repository to
the other. Granting the split without retiring this copy would leave that
risk in place. This directory stops being a second place code can drift
in — CHRONICLE.md's account of how that risk showed up once already is
part of why the grant reads the way it does.
