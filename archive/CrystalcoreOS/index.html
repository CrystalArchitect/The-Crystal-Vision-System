01 — Premise

Built for truth, consent, and real deployment.

Not a cloud service and not a research toy. CrystalCore is engineered to run reliably on low-power devices — Raspberry Pi 4/5, older laptops, embedded systems — in low-connectivity or sovereign environments, for personal, family, and advocacy use.

SOVEREIGNTY

Everything stays local

Full functionality with zero network. You hold the data, the reasoning, and the audit trail.

AUDITABILITY

No black boxes

Plain-JSON storage, inspectable rules, and a provenance link on every derived conclusion.

EDGE REALISM

<300 MB, ARM, microSD

A hard RAM budget with priority-weighted pruning, and atomic, checksummed persistence for flaky storage.

02 — Architecture

Four composable layers.

Each layer is independently useful. Together they form an auditable reason → remember → improve loop. Data and trust flow downward to the substrate; conclusions flow back up with provenance.

LAYER 04

CrystalMind agents

  • Four named reasoning policies: TruthSeeker, Guardian, Visionary, Creator.
  • Guardian holds a veto over conclusions built on weak ground.
  • Non-autonomous by design — agents act only when you invoke them.
▲ conclusions (with provenance)  │  invocations ▼
LAYER 03

CrystalEvolve learning

  • Population-based training of hybrid genomes (numeric params + symbolic rule chains).
  • Closed rule registry — mutation recombines vetted rules, never invents logic.
  • Gated fitness; deterministic, seeded runs; survivors protected from pruning.
▲ scored genomes  │  evaluation ▼
LAYER 02

CrystalFlow reasoning

  • Minimal scalar autograd (Value nodes with a full backward pass).
  • Inspectable symbolic reasoning chains; consent enforced fail-closed.
  • Coherence propagates conservatively: min(inputs) × rule_strength.
▲ facts (consent + coherence)  │  derived nodes ▼
LAYER 01

CrystalMemory substrate

  • Sparse, 8-bit-quantized tensors with coherence, consent, and priority metadata.
  • Durable payloads for text/structured conclusions that survive reloads.
  • Atomic + SHA-256-checksummed JSON persistence with best-effort recovery.

03 — Properties that hold across the stack

Three guarantees, verified by test.

These aren't aspirations — they're checked by the suite, including property-based tests that run each invariant across many randomized inputs.

[ CONSENT ]

Fail-closed

A consumer sees only what its permissions allow. A reasoning step that needs a forbidden input refuses outright — nothing is written, and the denial is logged.

[ COHERENCE ]

Confidence can't be faked

A conclusion is never more confident than its weakest input, and decays over time. Verified: output never exceeds min(inputs).

[ PROVENANCE ]

Always traceable

Every derived item links back to the exact inputs and the rule that produced it. Guardian can veto and physically remove a conclusion that lacks sound provenance.

04 — CrystalMind

Four stances, one council.

Each agent is a reasoning policy with a concrete stance — an evidence bar and a confidence factor, not a personality label. You invoke one agent, or convene a council; Guardian then reviews and may veto. No agent ever triggers another.

TruthSeeker
Demands high-coherence inputs. Refuses to conclude from weak evidence.
Guardian
The safety reviewer. Inspects a conclusion's real coherence and provenance, and vetoes — removing it from memory — when it stands on insufficient ground.
Visionary
Explores. Tolerates lower coherence to surface possibilities, but its conclusions are mathematically marked speculative.
Creator
Synthesises durable artifacts — position statements, drafts — from the available evidence.

05 — Quick look

Store evidence. Reason. Keep the trail.

Encoding data tags it with consent and priority; retrieval enforces both. Reasoning writes conclusions back with provenance. Here's the substrate in a few lines. 

# Standard library only — NumPy optional, not required.
from src.crystal_memory import CrystalMemory

memory = CrystalMemory(max_ram_mb=256)

# Encode with consent flags (bit 0 = user, bit 1 = family) and priority.
nid = memory.encode(
    data=[1.5, 2.3, 0.0, 4.8],
    coherence_boost=0.9,
    consent_flags=3,
    family_priority=1.2,
)

result = memory.retrieve(nid)   # consent + coherence enforced
print(result)

Run the full suite with python3 run_tests.py — no pytest required. Two end-to-end demos ship in examples/: a family decision pipeline and a policy-drafting council.

Vision · aspirational · not current capability

Where this is meant to go

CrystalCore is the sovereign-edge foundation for a longer-horizon vision — TerAustralis Incognita — that imagines consent- and provenance-respecting intelligence extending responsibly outward, guided by relational, Songlines-inspired protocols and a sovereign-futures ethic: truth as anchor, individual and family agency, and resistance to structural distortion.

That vision includes ambitions well beyond today's code — among them long-duration autonomous systems and self-replicating probes. Formal methods (TLA+ / Apalache model checking, mission-time LTL runtime monitors) are the right tools for systems at that level of criticality, and are part of the intended roadmap.

line of demarcation — what exists today: four Python layers, 118 passing tests, two demos, running offline on commodity hardware. Everything in this panel is direction, not a description of the current system.
