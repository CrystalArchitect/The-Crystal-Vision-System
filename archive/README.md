# Archive

Superseded material kept for provenance (Repository principle 3). Nothing
here is maintained, nothing here is production, and **nothing new should be
built on anything in this folder** — it exists so history stays checkable,
not so it stays usable.

Internal paths and claims inside archived material describe the repository
*as it was* and are deliberately left unfixed.

## One deliberate exception: a retired name

That rule has exactly one exception, recorded here rather than left silent.

The edge companion carried a different name through the early prototypes. That
name is retired and is not to be reintroduced anywhere in this project — see
*A note on borrowed and retired words* in [`mythos/NAMES.md`](../mythos/NAMES.md).
Retirement was taken to cover this folder too, so archived documents, scripts,
and the batch launchers' filenames were rewritten to the current names rather
than preserved as written.

This is a real cost and worth naming: these files no longer read exactly as they
did when they were snapshotted. Nothing else about them was touched — no paths
corrected, no claims updated, no stale statements repaired. Only the retired
name changed, and only because "not to be reintroduced" does not sit alongside
"kept verbatim in the archive."

Where a document needs to refer to the retirement itself, it does so without
reprinting the word. A page that lists a name is still a page that uses it.
