## 0. Status

This brief names the method used to write Documents 16, 17 and 18. It is not a fourth job. Catch remains recover/refurb/fuel. Gate remains consent at the interface. CICH remains a personal scan.

The protocol is: clarify the claim, surface assumptions, generate alternatives, state a prediction, record confidence, check reality later. No mystique without a ledger.

This document lives on the proposal site. It is not a door on www.teraustralis.com.au.

## 1. Definition

A sitting is a dated, written pass over one claim. It produces a brief that can be wrong in public. It does not produce a creed, a partnership, or a selected berth.

If a page cannot name what would prove it false, it is not a sitting. It is advertising.

## 2. Six steps

| Step | Action | Fail if |
|---|---|---|
| 1. Claim | One sentence. Built or Vision, labelled. | Two jobs in one sentence. Partnership implied. |
| 2. Assumptions | What must be true for the claim to hold. Named, not vibes. | Hidden geography, hidden consent, hidden plant. |
| 3. Alternatives | At least one other reading that still fits the public record. | Only the preferred story survives. |
| 4. Prediction | What the world will show if the claim is right. Dated if possible. | Unfalsifiable future (“someday”). |
| 5. Confidence | A number or a band, with the reason it is not 1.0. | Certainty as identity armor. |
| 6. Check later | Who looks, at what, by when. Reality is the referee. | No date, no owner, no artifact. |

CICH calls the same loop ESF. Document 17’s gate is a different object (runtime consent). Do not fuse the words.

## 4. Record (minimum)

A sitting record, when kept, holds:

- Date
- Claim (one sentence)
- Built or Vision
- Assumptions (list)
- Alternatives (at least one)
- Prediction
- Confidence (band)
- Check: artifact, date, owner
- Result (empty until the check)

A page on this site can stand in for the record. A private ledger is allowed. A speech is not a record.

## 5. Binding consent (unchanged)

If a place is named, Traditional Owners first. FPIC is law, not a preference rank. Document 16 §5 and Document 06 hold the floor. This protocol does not weaken it.

Country is not an assumption you can skip in step 2.
