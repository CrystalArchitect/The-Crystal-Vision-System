Application Structure: App.tsx & Routing

Central Router

Utilizes Wouter for lightweight, client-side routing, mapping the Incognita Lattice across Home, Codex, and Starline paths.

Global Contexts

Orchestrates the ThemeProvider (OKLCH), Tooltip, and Toast notifications to ensure a unified 'Deep-Time' experience.

Resilience Layer

Wraps the entire application in an ErrorBoundary to maintain sovereign stability even during transmission failures.

function App() {
return (
  <ErrorBoundary>
    <ThemeProvider>
      <TooltipProvider>
        <Router /> // Wouter Switch
      </TooltipProvider>
    </ThemeProvider>
  </ErrorBoundary>
);
}
