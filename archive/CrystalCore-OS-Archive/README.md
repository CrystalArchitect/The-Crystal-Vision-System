# CrystalCore.OS — the Crystal Architecture Archive

The portfolio's **system ledger** and **knowledge base**. This repository
holds no application code. It documents the other ten.

If this archive and a primary source ever disagree, the primary source is
right and this archive has a bug — open a correction per
[`knowledge-base/12-CONTRIBUTING.md`](knowledge-base/12-CONTRIBUTING.md).

## The maturity ladder

`STATUS.md` grades everything on the same five rungs, and they mean what
they say — nothing is filed higher than it earns:

**Running** · **Built, not currently running** · **Exists as a document** ·
**Designed, not built** · **Concept only**
