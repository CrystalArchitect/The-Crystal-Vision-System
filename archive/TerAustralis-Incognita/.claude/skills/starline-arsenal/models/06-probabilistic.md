# 06 — Probabilistic Thinking (The Predictors)

**Purpose:** Replace points with ranges. Use base rates, not stories.

**CrystalCore mapping:** Register ARCHIVE | Primitive track() with uncertainty | Store as distribution, not fact

## Core Questions — Run these, do not summarize

1. What is the base rate for this class of event?
2. What is the range, not the point estimate? 10% / 50% / 90%?
3. What would have to be true for the extreme to happen?
4. Where are we overconfident vs calibrated?
5. What bet would we take at these odds?

## Required Concrete Output — No vague labels

- Base Rate
- Range Estimate (10/50/90)
- Overconfidence Audit
- Bet Test

## Evidence → Interpretation → Experiment → Record

- **Evidence:** What was measured / observed?
- **Interpretation:** What gap / affect / loop does this reveal?
- **Experiment:** Smallest test to verify?
- **Record:** CHRONICLE entry as ARCHIVE / LOOM / FORGE / MIRROR

## Anti-Pattern

Do not just name "Probabilistic Thinking". Produce the artefact listed above. If no artefact, you have not run the model.
