# 03 — Scale Thinking (The Deconstructors)

**Purpose:** Test what breaks and what emerges at 10x, 100x, 1000x.

**CrystalCore mapping:** Register LOOM + FORGE | Primitive detect_gap() | Anticipate state store growth

## Core Questions — Run these, do not summarize

1. What breaks first at 10x? At 100x?
2. What cost becomes zero at scale? What cost explodes?
3. What property only emerges at scale?
4. What must become modular / automated?
5. What is the carrying capacity?

## Required Concrete Output — No vague labels

- Scale Failure List (10x/100x/1000x)
- Zero-cost List
- Emergent Property List
- Modularization Requirements

## Evidence → Interpretation → Experiment → Record

- **Evidence:** What was measured / observed?
- **Interpretation:** What gap / affect / loop does this reveal?
- **Experiment:** Smallest test to verify?
- **Record:** CHRONICLE entry as ARCHIVE / LOOM / FORGE / MIRROR
