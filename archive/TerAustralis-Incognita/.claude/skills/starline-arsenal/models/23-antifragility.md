# 23 — Antifragility (The Adaptors)

**Purpose:** Find what gains from shock and disorder instead of just surviving it.

**CrystalCore mapping:** Register ARCHIVE + FORGE | Primitive track() stressors, gain from disorder | Resilience returns to baseline; antifragility improves past it

## Core Questions — Run these, do not summarize

1. What stress, volatility, or disorder is this system exposed to?
2. Does this get better, the same, or worse after a shock (fragile / robust / antifragile)?
3. Where is hidden fragility masked by a long period of calm?
4. What small, frequent stressors would build strength for a large rare one?
5. What optionality lets us gain disproportionately from an upside surprise?
