# 28 — Regression to the Mean (The Predictors)

**Purpose:** Catch when an extreme reading is drifting back toward average on its own, rather than revealing a stable type.

**CrystalCore mapping:** Register ARCHIVE | Primitive track() extreme reading against expected pull | An extreme tail is often luck plus noise, not a character trait

## Core Questions — Run these, do not summarize

1. What reading was extreme?
2. What is the less-extreme value we'd expect on a second look?
3. Was the same noisy measure used both to sort the case and to judge it?
4. What happens if we wait for a second, independent sample before concluding anything?
5. Are we about to treat one tail reading as a fixed type?

## Required Concrete Output — No vague labels

- Extreme Reading
- Expected Pull (less-extreme next value)
- Second-Sample Plan
- Do-Not-Type List (conclusions this does not license)

## Evidence → Interpretation → Experiment → Record

- **Evidence:** What was measured / observed?
- **Interpretation:** What gap / affect / loop does this reveal?
- **Experiment:** Smallest test to verify?
- **Record:** CHRONICLE entry as ARCHIVE / LOOM / FORGE / MIRROR

## Anti-Pattern

Do not just name "Regression to the Mean". Treating a single extreme score as someone's fixed character, instead of waiting for a second sample, means you have not run the model.
