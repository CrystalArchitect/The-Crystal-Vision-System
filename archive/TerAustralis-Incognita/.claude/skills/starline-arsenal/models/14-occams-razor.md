# 14 — Occam's Razor (The Deconstructors)

**Purpose:** Cut competing explanations down to the one with fewest assumptions that still fits the evidence.

**CrystalCore mapping:** Register LOOM | Primitive detect_gap() between explanations | Complexity that isn't earning its keep is a gap, not rigor

## Core Questions — Run these, do not summarize

1. What are all the competing explanations on the table?
2. How many unproven assumptions does each one require?
3. Which explanation still fits all the evidence with the fewest moving parts?
4. What is being added for elegance rather than necessity?
5. What would we lose by cutting the extra assumption?

## Required Concrete Output — No vague labels

- Explanation List (ranked by assumption count)
- Assumption Count per Explanation
- Simplest-Sufficient Pick
- Cut List (what got trimmed and why)

## Evidence → Interpretation → Experiment → Record

- **Evidence:** What was measured / observed?
- **Interpretation:** What gap / affect / loop does this reveal?
- **Experiment:** Smallest test to verify?
- **Record:** CHRONICLE entry as ARCHIVE / LOOM / FORGE / MIRROR

## Anti-Pattern

Do not just name "Occam's Razor". Produce the artefact listed above. If no artefact, you have not run the model.

## Cross-references

[Provenance Stack](32-provenance-stack.md) — a claim resting on a low evidence tier (folk etymology, an unreferenced website, a viral meme) is exactly the kind of unearned complexity Occam's Razor should cut. Run Provenance Stack first to find the tier, then Occam's Razor to decide what survives.
