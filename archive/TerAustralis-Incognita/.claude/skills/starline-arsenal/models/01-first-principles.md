# 01 — First Principles (The Deconstructors)

**Purpose:** Strip to irreducible truths. Separate evidenced from assumed.

**CrystalCore mapping:** Register FORGE + ARCHIVE | Primitive track() + detect_gap() | Grounding before synthesis

## Core Questions — Run these, do not summarize

1. What is the absolute irreducible truth here? What cannot be disassembled further?
2. What are we assuming that we have not measured?
3. What would we build if we started from zero with only what is evidenced?
4. What belief, if false, would break this?
5. What does physics / economics / code force to be true regardless of opinion?

## Required Concrete Output — No vague labels

- Bedrock List (irreducible truths)
- Assumption List (unmeasured beliefs)
- Zero-based Rebuild Sketch
- Falsifier Test

## Evidence → Interpretation → Experiment → Record

- **Evidence:** What was measured / observed?
- **Interpretation:** What gap / affect / loop does this reveal?
- **Experiment:** Smallest test to verify?
- **Record:** CHRONICLE entry as ARCHIVE / LOOM / FORGE / MIRROR

## Anti-Pattern

Do not just name "First Principles". Produce the artefact listed above. If no artefact, you have not run the model.
