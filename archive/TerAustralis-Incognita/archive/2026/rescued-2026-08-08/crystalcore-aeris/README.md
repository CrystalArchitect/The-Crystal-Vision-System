# CrystalCore.OS — AERIS / VAULT 12 Edition

Golden continuation node theme for the multiplanetary desktop OS.

**Live Demo:** [https://crystalcore-aeris.vercel.app](https://crystalcore-aeris.vercel.app)

## Features

- AERIS boot with golden feather + floating animation
- Central VAULT 12 Continuation Node with activate pulse, light helix & audio feedback
- Draggable glass-morphism windows (mouse + touch)
- Mars Clock (live sol), Starship Telemetry, News Feed, Terminal
- Golden / cyan energy palette, floating crystalline pyramids
- Terminal commands: `vault`, `aeris`, `activate`, `node`, `mars`, `starship`, `status`, `about`
- Pure single-file HTML/CSS/JS

## Run locally

```bash
git clone https://github.com/CrystalArchitect/CrystalCore-AERIS.git
cd CrystalCore-AERIS
open index.html
```
