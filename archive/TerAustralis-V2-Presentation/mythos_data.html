Mythos Data Structure: mythos.ts

Centralized Store

The mythos.ts file acts as the single source of truth for the entire Incognita Lattice. It houses all narrative assets, from deep knowledge chapters to starline transmissions.

Collections

Data is organized into high-level collections:
• Codex: The core philosophical pillars.
• Transmissions: Real-time starline updates.
• Stories: Intimate "Stories of Presence".

MythosChapter Schema
Field Type Description
id string Unique identifier for routing
title string Main chapter heading
content string Markdown-formatted narrative
tags string[] Thematic categorization
readTime number Estimated engagement duration
