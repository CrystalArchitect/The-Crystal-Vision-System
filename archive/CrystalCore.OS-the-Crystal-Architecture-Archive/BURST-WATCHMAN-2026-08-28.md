# Burst Watchman — 2026-08-28

**Label:** Designed (ops pattern). Science claim is only: the pattern was written down this date.
**Owner:** Crystal Arena-Turner / TerAustralis Incognita

## Statement

Do not run a standing swarm. Run a watchman. Spin a workforce when a trigger is real. Persist one verified artifact. Reset.

## Loop

1. Watchman idle (cheap).
2. Trigger passes a falsification gate (is this work, or dashboard theatre?).
3. Register the Cell (job, bound, exit).
4. Workers appear for the bound only.
5. Artifact written and checked.
6. Workers disappear.
7. Ledger line: what was produced, what it cost, what did not happen.

## Falsification gates

- Node graphs are not workers.
- Dollar needles on a mock UI are not invoices.
- "300 agents" without a file is Story wearing a Science coat.
- Human veto remains after any vendor demo.

## Fit to existing canon
