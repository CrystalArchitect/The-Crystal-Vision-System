# TerAustralis Incognita v2

This repository contains the source code for the TerAustralis Incognita v2 website, featuring a 'Deep-Time Dreaming' aesthetic and a sovereign space-age vision.

## Repository Structure
- `client/`: React 19 frontend code.
- `server/`: Backend server (placeholder for static template).
- `shared/`: Shared types and constants.
- `TERAUSTRALIS_V2_COMPLETE_SOURCE.md`: A single file containing all core source code for easy ingestion by AI models like Claude.

## Key Features
- Immersive Codex Reader
- Starline Protocol integration
- CrystalCore.OS simulation
- Data Sovereignty and Local-First design
