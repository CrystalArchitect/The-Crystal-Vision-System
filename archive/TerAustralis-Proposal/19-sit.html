Sitting protocol

Method brief. Not a product. Not a homepage item. Reality remains the referee.

Method · not a fourth job

0. Status

This brief names the method used to write Documents 16, 17 and 18. It is not a fourth job. Catch remains recover, refurbish, fuel. Gate remains consent at the interface. CICH remains a personal scan.

The protocol is: clarify the claim, surface assumptions, generate alternatives, state a prediction, record confidence, check reality later. No mystique without a ledger. It is not a door on www.teraustralis.com.au.

1. Definition

A sitting is a dated, written pass over one claim. It produces a brief that can be wrong in public. It does not produce a creed, a partnership, or a selected berth.

If a page cannot name what would prove it false, it is not a sitting. It is advertising.

2. Six steps

StepActionFail if
1. ClaimOne sentence. Built or Vision, labelled.Two jobs in one sentence. Partnership implied.
2. AssumptionsWhat must be true for the claim to hold. Named, not vibes.Hidden geography, hidden consent, hidden plant.
3. AlternativesAt least one other reading that still fits the public record.Only the preferred story survives.
4. PredictionWhat the world will show if the claim is right. Dated if possible.Unfalsifiable future (“someday”).
5. ConfidenceA number or a band, with the reason it is not 1.0.Certainty as identity armor.
6. Check laterWho looks, at what, by when. Reality is the referee.No date, no owner, no artifact.

CICH calls the same loop ESF. Document 17’s gate is a different object (runtime consent). Do not fuse the words.

4. Record (minimum)

A sitting record, when kept, holds: date; claim (one sentence); Built or Vision; assumptions; at least one alternative; prediction; confidence band; check (artifact, date, owner); result (empty until the check).

A page on this site can stand in for the record. A private ledger is allowed. A speech is not a record.

5. Binding consent (unchanged)

If a place is named, Traditional Owners first. FPIC is law, not a preference rank. Document 16 §5 and Document 06 hold the floor. This protocol does not weaken it. Country is not an assumption you can skip in step 2.

6. Out of scope

  • A homepage card or header item on www.teraustralis.com.au
  • A CrystalCore software module named Sitting
  • A score that “beats” another lab
  • Partnership, endorsement, or lab affiliation
  • Replacing Catch, Gate, or CICH

7. One sentence

Write the claim so it can die. Then see if it does.

Gold is the grid. The dark is still Country.
