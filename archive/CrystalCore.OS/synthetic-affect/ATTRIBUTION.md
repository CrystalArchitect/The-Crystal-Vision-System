## Contributing AI tools

Per the umbrella repository's `docs/ai/` convention, each AI tool that
contributes is named for what it did.

| Tool | Contribution |
|---|---|
| **Meta AI** | Drafted the v0.1 reference implementation delivered 12 August 2026 — the module layout, the four-primitive surface, the JSONL cycle log, and the deterministic offline stub that makes the logs reproducible. The structure of this release is that draft's. |
| **Claude** | Ran the draft, found and fixed the defects recorded in `CHRONICLE.md` — the unreachable `closed` label, the unimplemented state store, self-graded closure outcomes, module-global runtime wiring, the clipped figure — and wrote the test suite that holds them closed. |

The draft is credited because it did real work, and the defects are recorded
because they were real. Both belong in the record: crediting the contribution
without noting what the run exposed would be the more flattering account and the
less true one.
