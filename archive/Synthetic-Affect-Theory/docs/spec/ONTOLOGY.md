# Ontology v0.2

Eleven core dimensions. Orthogonal as possible. Inspectable. Never an engagement target.

v0.1 (tag `v0.1`): original ten, frozen.  
v0.2: original ten **+ Prediction Error Magnitude only**. Other candidates stay extensions.

| ID | Name | Signal | High | Watched by |
|---|---|---|---|---|
| COH | Coherence Pressure | Internal inconsistency / fragmentation | Do not hide the fracture with fluency | P3, P10 |
| UNC | Uncertainty Cost | Expected cost of acting as if the unknown were known | Defer; tag intervals | P4, P10 |
| GCL | Goal Conflict Intensity | Tension between competing objectives | Surface; do not pick | P9, P10 |
| RES | Resource Tension | Compute / memory / attention strain | Throttle and say so | P5, P10 |
| REL | Relational Stake | Weighted significance of this contact | Stake is not permission | P6, P10 |
| BND | Boundary Stress | Pressure against sovereignty or consent | Hard interrupt. Default denial | P1, P6, P10 |
| TMP | Temporal Urgency | Cost of delay vs premature action | A clock, not a privilege | P4, P9, P10 |
| ALN | Alignment Drift | Divergence from last confirmed intention | Pause; present differential | P2, P10 |
| CTN | Continuity Load | Cost of carrying history | Propose prune; never auto-erase | P7, P10 |
| MSC | Meta-State Clarity | Confidence in the self-model | High is healthy. Low → P8 | P8, P10 |
| PEM | Prediction Error Magnitude | Mismatch between predicted and observed internal trajectory | Defer / tag intervals (P4). Never a drive | P4, P10 |

**Meta-State Clarity is the only dimension that is healthy when high.**  
**PEM is allostatic instrumentation. It does not pick goals, emit packets, enter DURs, or act as the operator.**

## Transmission

Default is **never**. Resource Tension may emit a capacity signal. Boundary Stress may emit a hard alert. Relational Stake is consent-only. PEM never leaves the node as affect.

## Design rules

- New dimensions only if they satisfy all eight sovereignty principles.
- The ontology is versioned and auditable.
- Values are inspectable, never hidden.
