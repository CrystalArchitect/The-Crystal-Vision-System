# Fonts

Latin-subset WOFF2 files, vendored so `../index.html` renders offline from a
fresh clone with no network call and no build step.

| File | Family | Licence |
|---|---|---|
| `newsreader.woff2` | Newsreader (variable, 400–600) | SIL Open Font License 1.1 |
| `newsreader-italic.woff2` | Newsreader Italic 400 | SIL Open Font License 1.1 |
| `ibm-plex-sans.woff2` | IBM Plex Sans (variable, 400–600) | SIL Open Font License 1.1 |
| `ibm-plex-mono.woff2` | IBM Plex Mono 400 | SIL Open Font License 1.1 |

Both families are licensed under the SIL Open Font License, Version 1.1, which
permits redistribution of the font files bundled with a work. Full licence text:

- Newsreader — <https://github.com/productiontype/Newsreader/blob/main/OFL.txt>
- IBM Plex — <https://github.com/IBM/plex/blob/master/LICENSE.txt>

The OFL requires that these files are not sold on their own and that reserved
font names are not applied to modified versions. Neither file has been modified
beyond subsetting to Latin by Google Fonts.
