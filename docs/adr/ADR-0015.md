# ADR-0015: Stop growing the constellation — no new GitHub repository without an ADR

**Status:** Accepted (merged as PR #118, 2026-08-19)
**Date:** 2026-08-20

## Context

[`ADR-0011`](ADR-0011.md) adopted three *projects* (umbrella, Crystal Core,
Crystal Vision) and deferred the *repository count*. The Migration Plan's
Stage 3 said split `-Code` only when cadences, licensing, contributors, or
CI actually fight. That gate was never meant as permission to mint a new
GitHub repository every time a session wanted a clean folder.

(Code), the proposal site, and the HTML `CrystalCore.OS` desktop. Other
github.io URLs exist; they are not a reason to add a fourth face.

The Code `STATUS.md` leftover "SAT dedicated-repo split" is already
satisfied by `Synthetic-Affect-Theory-`. Splitting it again is the same
habit this ADR stops.

New repositories have been cheaper than finishing the old ones. That is
the failure mode.

## Decision

1. **No new GitHub repository** under `CrystalArchitect` without a new
   ADR that names why the existing landing table cannot hold the work,
   **and** the maintainer creating the repository. Agents do not create
   repositories. Grok Build does not create repositories. A sandbox is
   not a repository.
2. **Next work lands in an existing living repo**, using this table:

   | Kind of work | Lands in |
   |---|---|
   | Canon, ADRs, mythos, governance | `TerAustralis-Incognita` |
   | Engine, consent transport, public site | `TerAustralis-Incognita-Code` |
   | Companion runtime and its tests | `Clementine-ai-companion` |
   | Formal proposal / Southern Pillar case | `teraustralis-proposal` |
   | SAT research | `Synthetic-Affect-Theory-` (already exists) |
   | HTML desktop | `CrystalCore.OS` (already exists) |
   | Fleet STATUS | `CrystalCore.OS-the-Crystal-Architecture-Archive` |

3. **`teraustralis-incognita-v2` is not a fourth OS and not a successor.**
   It is stalled. Resume there only by maintainer decision. Default for
   new engineering is `-Code`.
4. **ADR-0011 Stage 3 is unchanged and still closed.** Splitting `-Code`
   into core/vision repositories still requires those criteria *and* this
   ADR's "new repository" gate. This ADR does not split anything.
5. **Archived and frozen provenance stay frozen.** GitHub-archive of
   remaining unarchived frozen repos is a maintainer click, not this PR.
6. **Decided-NOT list:** no new OS, no SAT-v2 repo, no `CrystalCore.OS-v3`,
   no App Builder sandbox promoted to GitHub, no locked-name change, no
   Constitution amendment.

## Consequences

- The weave has a default again: open a branch on a named living repo,
  not a new empty one.
- Stage 3 can still fire later. When it does, it takes an ADR, not a
  session that "needed a clean folder."
- The 2026-07-24 six-repo survey in
  [`Project-Boundaries.md`](../governance/Project-Boundaries.md) stays as
  written (it was true that day). The 19-count lives here and in a dated
  addendum there.
- Creative Grok still diverges. Divergence that wants a new GitHub
  repository composts unless it survives this gate.

*Non Solus.*
