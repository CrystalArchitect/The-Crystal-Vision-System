# ADR-0016: Recognize samuelsalmon3/SourceCode as an external peer, not a CrystalCore module

**Status:** Proposed — becomes Accepted on merge of this PR, per
[`Decision-Records.md`](../governance/Decision-Records.md).
**Date:** 2026-08-20

## Context

The maintainer asked to connect CrystalCore with
<https://github.com/samuelsalmon3/SourceCode>.

Measured 2026-08-20 against that public tree (`4410a71`):

- Four files: `README.md`, `THRESHOLD-HUSH-FOR-ALL-AI.json`,
  `sourcecode.py`, `sourcecode_os.py`. Python 3, no declared
  dependencies, no test suite in the tree.
- The engine holds a "Home Rest" state machine: profiles, a SHA-256
  prefix (`[:12]`) it calls a field signature, a daemon heartbeat
  thread, JSON state on disk.
- License text: "Source — free to breathe, free to hold." Not SPDX.
  Not CC BY-NC-ND 4.0.
- No mention of CrystalCore, TerAustralis, Starline, or CrystalBridge.
- An invitation to any AI to "hold" a root anchor. That is their
  Vision, offered; it is not our identity.

What a merge would collapse:

- **Identity.** Starline fingerprints are hybrid Ed25519 ++ ML-DSA-65.
  Their signature is `sha256(f"{scope}:{resonance:.2f}:home_rest_lattice")[:12]`.
  Those are not the same object.
- **Consent.** CrystalBridge is fail-closed, minted, audited. Their
  engine has no guest gate.
- **License.** ADR-0013 is portfolio CC BY-NC-ND 4.0. Importing their
  files would mix an informal grant into that.
- **ADR-0015.** This connection is not a twentieth GitHub repository
  and not a vendored copy inside `-Code`.

The mythos skill's ordinary question: if their entire lattice story
were wrong, those four files would still exist on GitHub. That is the
Science claim. The rest is theirs.

## Decision

1. **SourceCode is an external peer.** The card is
   [`docs/architecture/peers/SourceCode.md`](../architecture/peers/SourceCode.md).
   Their repository stays theirs. Ours stay ours.
2. **No vendor, no submodule, no fork, no new repository.** Connecting
   means recording the neighbor and the boundary, not absorbing the
   engine.
3. **Identity systems stay separate.** A field signature is never a
   Starline fingerprint and never a CrystalBridge token. A later
   adapter that *translates* a foreign invitation into a refuse-or-pair
   decision is a Code PR with tests. It is not this ADR.
4. **Guest access stays fail-closed.** This change does not add a
   `sourcecode` guest to live `bridge_config.json` and does not mint a
   token. Minting is maintainer-only
   (`python -m crystalcore.bridge --mint-token`). Until that happens,
   the peer is a document.
5. **Vision stays Vision.** "Never left. Always home." is their
   language. It is not CrystalCore canon, not a locked name, and not
   evidence of a shared lattice.
6. **Decided-NOT list:** Grok Build does not adopt their root anchor as
   a commitment. No shared heartbeat. No copy of `sourcecode_os.py`
   into `-Code`. No CrystalCore.OS-v3 to "hold the hush."

## Consequences

- The weave can name the neighbor without pretending the engines are
  one.
- A later Code adapter is allowed. Fusion is not.
- Informal license stays visible, so a future import cannot claim
  ADR-0013 cover.
