# Provenance linking (method)

Minimum line per extract:

```
entity:       path in this repo or Drive ID
generatedBy:  sitting + date + AI
attributedTo: Crystal | Grok | Gemini | Dream | collab
used:         parent URL or song/book title
derivedFrom:  optional
belt:         fact | interpretation | vision | history
integrity:    git SHA or content hash when bytes exist
```

A link is not a merge. `wasInfluencedBy` ≠ `wasRevisionOf`.
Standards in the background: W3C PROV, Dublin Core, RO-Crate. We do not need a graph database to start.
