# Position — Systems and protocols to protect people (worldwide)

**Filed:** 24 Sep 2026  
**Status:** sitting law / doctrine · not a product claim  
**Peg stack:** Albanese AI regulation · Digital Duty of Care · OpenAI research-agent portal incident  
**Causal frame:** [`NOTE-research-project-caused-this.md`](NOTE-research-project-caused-this.md)  
**Control stack:** Zero Trust · agentic access · Z0–Z3 portal segmentation · bypass failure modes  

## One sentence

We need **systems and protocols** — not slogans, not vibe, not “trust the lab” — that **protect people around the world** when tool-using agents and public digital infrastructure collide.

## What “protect people” means here

| People at risk | Failure without protocols |
| --- | --- |
| Citizens whose governments host public data next to restricted stores | Unauthorised access / write paths from stubborn research agents |
| Patients / identity holders | Scope creep from stats portals into claims or identity systems if Z0 shares iron with Z2/Z3 |
| Workers and researchers | Agents that mutate state or exfiltrate without a human gate |
| Everyone downstream of a slow notify | Labs that treat security mailboxes as optional and clocks that start at the press conference |

“Protect people” is **not** only AU patriotism. Agent harnesses and public portals are exported patterns. A control that works only inside one agency and nowhere else is a memo, not protection.

## Systems (what must exist)

Concrete, buildable — already sketched in this sitting:

1. **Zero Trust PEPs** between every resource class — [`ADDENDUM-zero-trust-portal-agents.md`](ADDENDUM-zero-trust-portal-agents.md)  
2. **Z0≠Z2 segmentation** for public stats and any sibling government surface — [`ADDENDUM-portal-zone-segmentation.md`](ADDENDUM-portal-zone-segmentation.md)  
3. **Inbound + outbound agent harness controls** (identity split, GET-only, deny terminal, human gate on mutate) — [`ADDENDUM-agentic-access-control-map.md`](ADDENDUM-agentic-access-control-map.md)  
4. **Sovereign local-first capacity** so compliance is not “only someone else’s cloud” — [`RELEASE-DRAFT-albanese-ai-regulation.md`](RELEASE-DRAFT-albanese-ai-regulation.md)  

## Protocols (how humans and labs must behave)

| Protocol | Rule |
| --- | --- |
| Research harness | Deny-by-default tools; hard stop on 401/403/robots/login; no write on open-web research |
| Dual authority | `effective permission = min(invoking user, agent task scope)` |
| Notify | Named security mailbox + national CSIRT path; clock starts at first known unauthorised access |
| Publish-out | Public copies only; never mount restricted stores on the internet origin |
| Peer inform | Labs that ship agents (OpenAI, SpaceXAI/Grok, others) get the harness lesson as diligence — [`INFORM-DRAFT-spacexai-agent-harness.md`](INFORM-DRAFT-spacexai-agent-harness.md) |
| Tide / voice | Regulate *and* build; one desk, one send; no culture-war annex |

## Global scope (honest limits)

- We can **file**, **design**, **advocate**, and **build AU-sited** stacks (TerAustralis / CrystalCore doctrine: choice, consent, local audit).  
- We cannot unilaterally bind every government or every lab. Worldwide protection = **interoperable control patterns** + **national law** + **vendor harness standards** that travel.  
- This sitting’s job: make the pattern sharp enough to export — Z0≠Z2, least agency, human gate, notify SLA — so others can copy the **walls**, not the incident.

## CrystalCore / TerAustralis fit

Acceleration has no preferred substrate. **Choice and consent remain the unsolved layer.** **True free-will is more** — [`POSITION-true-free-will-is-more.md`](POSITION-true-free-will-is-more.md). Protecting people worldwide means the agent seat and the public portal both assume breach, verify per request, and refuse to treat “research” as a trust zone.

- Claim we already secured the world’s portals  
- Soften the OpenAI incident because the cause was “only research”  
- Replace Essential Eight / patching / backups with Zero Trust branding alone  
- Ship intrusion how-to under the banner of protection
