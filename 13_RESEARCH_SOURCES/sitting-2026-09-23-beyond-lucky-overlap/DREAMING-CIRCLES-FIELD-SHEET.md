```
        ┌──────── RECORD ────────┐

        └───────────┬────────────┘
                    │

        │  POOL                  │

        └───────────┬────────────┘
                    │
```

## Five beats (always in this order)

| # | Beat | Do | Don’t |
| --- | --- | --- | --- |
| 1 | **Record** | Name the paid runs that made the trees | Invent runs that didn’t happen |
| 2 | **Pool** | List which trees enter this circle + consent | Mix mythos trees into product routing |
| 3 | **Dream** | Write 2–3 alternate *policies* (what to try next time) | Change model weights / claim awakening |
| 4 | **Receipt** | Four lines, dated, small | “Alignment stable” as identity |
| 5 | **Gate** | Crystal: stamp / refuse / compost | Auto-promote to live |

## Minimum tree schema

```json
{
  "tree_id": "T-remake-hub-404",
  "domain": "ops",
  "consent": true,
  "nodes": [
    {
      "id": "n1",

      "outcome": "404 NOT_FOUND",
      "score": 0,
      "cost": "phone check"
    }
  ]
}
```

Score: 0 fail · 1 partial · 2 success (Crystal’s rubric, not the vendor’s).
