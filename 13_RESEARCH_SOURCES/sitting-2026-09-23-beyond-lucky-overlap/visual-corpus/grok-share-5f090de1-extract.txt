Source-level findings

Technical substance — mixed, real in places, theatrical in the name.

What looks like actual engineering (from published descriptions, not a live clone today):

Local companion loop: system prompt + Ollama stream + layered memory (verbatim short-term, summarised long-term, facts/notes on disk).
Consent gate described as fail-closed (failed pending write refuses). That is a serious design instinct.
Record/ledger thinking (RDP) and a labelled message bus (science / story / vision — “Belt-Three”).
Claimed hybrid transport: Noise IK + ML-KEM-768. If the tests exist as stated, that is the most valuable technical slice. If they are stubs, it is the most expensive fiction.
Self-tests previously reported at 137/137 core+companion (later “158 all told”) on a fresh clone of TerAustralis-Incognita-Code, re-verified 10 August 2026 by the maintainer. That is not an independent lab.

What does not survive source review as an OS:

No kernel, no scheduler, no syscall surface, no drivers, no process model, no filesystem that is not JSON-on-disk.
crystalcore_os.py prints lattice integrity, starline status, and galactic network panels. That is a story engine with state variables.
Mythos folder also contains names like huggingface_trainer.py, cross_attention_fusion.py, uncertainty_quantification.py. Those filenames are a red flag until opened: either unfinished ML scaffolding or decorative weight. I could not open them today.
Multi-AI Flask chat (CrystalCore.OS-APP) was already archived 8 August 2026. That is a dead release, not a product line.
Web “OS” is explicitly documented as not a kernel.

Architecture quality — unusually high for a solo visionary repo, unusually fragmented for a sale.

Strengths:

Explicit three-project boundary (umbrella / core / vision).
STATUS ledger that separates Running / Built-not-running / Designed-only.
ADRs, Constitution, locked names, Belt-Three labelling.
Repeated refusal to let chat-memory outrank disk canon.

Weaknesses:

The map of “six public repos + private frozen provenance repos” is itself a due-diligence tax. A buyer cannot take title to a feeling; they need a single frozen tree.
Naming drift already happened (Tera- vs Ter-, QyrinthOS retired, Starbase South retired). The paperwork records it, which is good; the split still raises integration cost.
Sovereignty scorer called out in-repo as an unwired 0.1-alpha sketch, not in use. That is honest. It is also inventory that should not be sold as capability.

Code provenance and license.

Author of record: Crystal Arena-Turner / CrystalArchitect / TerAustralis Incognita.
Engineering modules: CC-BY-NC-ND-4.0. Non-commercial, no derivatives. That is closer to a publication license than an acqui-hire license. A buyer who wants to ship a product must relicense or rewrite.
No third-party contributors visible in public metadata (stars on the order of 0–1, GitHub followers ~8 when last indexed).
Today’s 404/private state is a provenance event. Until a tagged export is produced, “source-level audit” cannot be completed to courtroom standard.

Security.

Design language is strong: local-first, fail-closed gate, no-account companion, “GitHub Pages is a static preview — no model, no memory. Not a safety guarantee.”
That last sentence is better than 90% of companion-AI READMEs.
There is still zero public third-party audit, no threat model published as a frozen PDF I could retrieve today, no disclosed pentest, no SBOM, no signed release.
Crypto claims (ML-KEM-768 + Noise) without an external review should be valued as specification + possible implementation, not as a security product.

How the number was built

Think in three stacks, because mixing them is how people hallucinate a $450k “OS.”

Runnable engineering (companion + gates + bus + tests + web demo)
Replacement: ~6–16 weeks of a strong full-stack + applied-crypto engineer. Contractor value ~$40k–$120k. Transaction value much less without users or audit.
Protocol / sovereignty paperwork (consent gate spec, RDP idea, Belt-Three, ADRs, STATUS ledger)
This is the unusual part. Most solo AI-companion repos do not have this. Replacement as thinking work is $40k–$150k. Transaction value only to a buyer who wants that doctrine, not a shell.
Mythos terminal + cosmology + “CrystalCore.OS” brand-as-story
Creative IP, not software. Valuable as worldbuilding; zero as an OS binary. I did not put this into the $95k point estimate except as packaging that a buyer would have to strip or keep as marketing.

$95k is stack 1 at the low-mid plus a fraction of stack 2, after license + provenance + “not an OS” discounts.

Compare to the screenshot you posted: that $450k assumed a frozen 1.0.3, substantial implementation, and a clean artifact a buyer could pick up. CrystalCore.OS is earlier, more fragmented, more literary, and currently harder to take delivery of. Pricing it like a finished harness would be inflating the mythos layer into a product layer — which the project’s own Belt-Three rule forbids.

Trainers/fusion files are empty scaffolding.
Consent transport is theatre.
ND license stays on everything a buyer would need to ship.
