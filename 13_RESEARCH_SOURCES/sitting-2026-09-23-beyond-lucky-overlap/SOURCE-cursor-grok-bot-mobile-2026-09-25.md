## One line

Grok Bot on **iPhone / Android** is the same cloud Bots + shared computer as desktop — Crystal can start work, approve steps, and review results away from the desk while Core Four / CapCut / desks continue in the cloud.

| Need | Detail |
| --- | --- |

| Plan | Paid individual Cursor · Cursor Teams · **or** SuperGrok / SuperGrok Plus / SuperGrok Heavy linked to Cursor |
| Net | Internet connection |

---

## Sign-in flow (ops)

1. Open Grok Bot → **Log In or Sign Up**  
2. Complete **Cursor** auth in browser → return to app  
3. If access is via SuperGrok: **Link Grok Account** → browser link → **Finished Linking? Refresh My Status**  
4. New users: first-run tour → first Bot → wait for shared computer setup  
5. Existing users: synced Bot list  
6. Enable notifications for result / question / approval (push still rolling out; in-app attention states remain)

## What mobile does **not** replace

- Advanced desktop controls and teach-by-demonstration  
- Editing routine schedule/instruction or testing routines (desktop)  
- Auto-post to X (X connector remains read-only — see automation peg)  
- Firing ElevenLabs itself — Crystal still pastes booth VO; mobile is for Bot assist / approve / review around that fire  
- Destiny proof / lyric dumps / Gabriel surveillance (sitting law unchanged)
