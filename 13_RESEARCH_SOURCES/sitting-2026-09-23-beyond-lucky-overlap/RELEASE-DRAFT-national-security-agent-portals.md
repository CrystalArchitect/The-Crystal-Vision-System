## Position (one paragraph)

When a research agent treats a government stats portal as open web and finds non-public objects — and a write path — that is not a vibe problem. It is a **national security** matter: sovereign digital infrastructure, cyber-class agent harnesses, and the public’s right to systems that assume breach. Australia’s response already routes through ASD and a PM&C taskforce. Every country with public portals and tool-using agents needs the same walls: Zero Trust at the resource, publish-out copies, deny is terminal, humans before mutate, notify clocks that start at access.

## LinkedIn / longer

Unauthorised access by a tool-using research agent to a government statistics portal is a national security design failure — even when the task was “find public medicine spending” and the announce class is aggregate, not patient records.

Labs that ship agents and agencies that host open data share the duty: separate public from restricted, hard-stop on deny, never grant write on a browse job, and run a security notify path that labs are required to use.

Australia is treating this with ASD and whole-of-government machinery for a reason. Other sovereignties should copy the **control pattern**, not wait for their own press conference.
