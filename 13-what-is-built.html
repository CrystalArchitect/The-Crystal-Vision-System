What Is Built

The verified record behind the proposal. Documents 01–12 argue for what should exist; this page records what already does — dated, tested, and public — under the project's own law: no dreamed line may pretend it was measured. The continuously maintained version is STATUS.md in the archive repository.

Running Now — Verified on a Fresh Machine, Dates Given

  • The CrystalCore engine (Python, open repository). A message bus whose validator rejects any message that does not declare its evidence layer; a consent gate that is fail-closed and revocable at runtime; memory kept separate from any model, so models remain swappable faculties. Re-verified on a fresh machine 10 August 2026 at repository head: 137/137 across every suite — the four core suites (74), the companion's tests (47), the consent gate's self-test (13, grown from 7 as scope and provenance checks were built), and the mesh stubs (3). CI runs the suites on every push.
  • Fabrication tooling with machine-checked output. A parametric enclosure generator (headless Blender, every dimension a named parameter) and an independent geometry checker in a different library — the generator does not grade its own work. Both printable parts pass every check: watertight, single-body, stated dimensions (8 August 2026). Labelled honestly: validated geometry is a surveyed solid, not yet a surveyed object — fit and strength stay unproven until the parts are printed.
  • Sydney Station (13 August 2026 invitation; on this site 20 August 2026) — sydney-station.html: two-campus collaboration invitation (Aerotropolis West + Westmead). Not a contract. Browser Smash/mint gyms were withdrawn the same day; they were teaching aids, not the Python engine.
  • A live, indexed site — www.teraustralis.com.au: self-generating sitemap, IndexNow notification on every deploy. Retrieved and cited as a source by Perplexity roughly 48 hours after DNS went live, recorded verbatim in the archive (8 August 2026).
  • Provenance anchored to Bitcoin. A deterministic SHA-256 manifest over the creative canon, timestamped via OpenTimestamps by CI, with each proof committed back into the repository (first proofs 31 July 2026). No wallet, no token, nothing traded — pure timestamping, verifiable by anyone with the repository and an ots client.
  • Two reproducible studies of AI behaviour (filed 8 August 2026): a four-round test of AI-delivered code against its own claims — each version run exactly once and reported honestly, until claims and code converged — and an eleven-way comparative record of AI responses to a single two-word prompt. The study code is standard-library Python, deterministic, and included in the public record.

Built, Awaiting Hardware — Stated Plainly

Clementine, the companion application a person actually talks to: local-first, and previously ran end-to-end on local models via Ollama. After a hardware loss, the recovered package (v0.13.4) imports cleanly and passes 19 of 20 offline tests on a fresh machine (24 July 2026). On 8 August 2026 the current interface completed its first full live sessions since the loss — boot, a streamed conversation turn, memory written to disk, and a second process waking with that memory and carrying it back into the model's context — against a scripted stand-in endpoint, recorded as machinery evidence and labelled exactly that. Every link in the chain is now surveyed except one: real model weights on hardware the project controls. That last step is deliberately the one that requires no cloud and no third party — which is the thesis, stated as an experiment.

Designed, Deliberately Not Built — Labelled Vision

The Lattice substrate, the node mesh, and the full TerAustralis vision are locked by the project's own Constitution as designed, not built, and every status document says so. The portfolio's ledger opens with its rule: "This file describes the state of the system, not the ambition of the system."

Governance You Can Audit

  • Consent is a runtime property. A public credit ledger where people enter only by their own evidenced public words — scoped to exactly what was asked, reversible at any time, no reason required. Models cannot consent; AI-generated texts are filed as received documents with authority weight zero, never as members or evidence.
  • Indigenous Data Sovereignty is a hard boundary, designed in from the start: "Not AI that contains Songlines. AI infrastructure capable of respecting the laws that already govern them." Practised, not only stated: work is held back whenever the consent door belongs to custodians rather than to the project.
  • A creative canon under settled rights — nineteen recordings catalogued with per-track rights fixed by dated receipts (8 August 2026), including one work removed because the grant was not the project's to make.

Prior Art, Conceded

Local-first assistants and companion applications are a crowded, healthy field; no claim is made to that ground. The narrower, checkable claim is the governance layer enforced at runtime — evidence-labelled messaging, fail-closed consent, model-agnostic identity — with the entire record public, dated, and independently verifiable.
