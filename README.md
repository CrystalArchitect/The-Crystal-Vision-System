# SAT public landing

Public claim page only. The specification stays in the private repo.

**Do not make `Synthetic-Affect-Theory-` public.**

## Publish (GitHub Pages)

On a phone:

1. Open [github.com/CrystalArchitect/sat-landing](https://github.com/CrystalArchitect/sat-landing)
2. **Settings** → **Pages**
3. Source: **Deploy from a branch**
4. Branch: **main** / **/** (root)
5. Save

Live URL after a minute:

`https://crystalarchitect.github.io/sat-landing/`

## Custom domain later

In the same Pages settings, set custom domain `sat.teraustralis.com.au` (or `www.teraustralis.com.au` path via the main site host). Then add a CNAME at the domain registrar pointing that name to `crystalarchitect.github.io`.

The live [teraustralis.com.au](https://www.teraustralis.com.au/) homepage is a separate host. Putting `/sat` *on that site* means adding a page in whatever built Clementine / Codex — not this repo.
