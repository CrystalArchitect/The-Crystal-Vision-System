# Protocol Omega

A personal boundaries practice: a daily bearing, four stations for naming what happened, and a private ledger.

**Drawer:** `10_ORIGINAL_CREATIVE`  
**Canon:** no (until Crystal stamps it)  
**Belt:** vision / practice tool

## How to open

Open [`index.html`](./index.html) in a browser (double-click or any static host). No build step.

## Persistence

Entries and daily marks are stored in **this browser only** via `localStorage` (`protocol-omega:v1:*`). Nothing is uploaded.

## Provenance

- Adapted from a Claude artifact share: https://claude.ai/artifact/Dyhq3oN217iAaVAVPAhqkV
- Captured 2026-09-16 into The Crystal Vision System.
- Claude frame-runtime / `window.claude.use('db')` removed; replaced with a localStorage adapter so the page works offline and outside Claude.
