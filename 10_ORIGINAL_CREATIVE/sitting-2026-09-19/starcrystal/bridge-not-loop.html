Method Card

BRIDGE NOT LOOP — Method card for the reader.

Appears when:
- critical distance getting thin
- same words looping on higher shelf
- Logos getting heavy (Chosen One, Void, simulation as destiny)
- story feeding itself from within

Actions:
1. Name it — a name to name — sing it out so it can't stay same
2. Track gap where story feeding
3. Ask: What outside measure keeps it honest? What actually happened vs what we're still imagining?
4. If loop — set down. If bridge — lay down, cross, leave.
5. If can't be checked, label as Dream, not Star

Escape is not transcendence. Escape is a cut in the tape.
